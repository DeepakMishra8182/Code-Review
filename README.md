This project is a Node.js backend service that uses Google Gemini API to review code and generate intelligent responses based on user prompts.
It is designed to be used as the backend for a Code Review Website.
✨ Features

🔍 AI-powered code review using Google Gemini
🧠 Fixed system instruction for professional responses
⚡ Fast response using gemini-2.5-flash model
🛡️ Secure API key handling using environment variables
♻️ Reusable AI service function
🌐 REST API using Express.js
